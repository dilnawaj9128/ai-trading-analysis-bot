Import a snapshot

Load a completed-candle snapshot from your bot. The file stays in this browser session.

Snapshot format

Use a markets object keyed by NIFTY50 or EURUSD. Each market has candles with time (ISO close time with timezone), open, high, low, close, and completed: true.

Optional signals entries use the same time, an integer horizon of 1, 5, or 15, signal, reason, origin (recorded or recomputed), and outcome (WIN, LOSS, PUSH or PENDING).

Optional market fields include provider, quality, missing, and paperTrades. Optional top-level fields are tests and stage.
